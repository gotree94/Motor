# 서보모터 원리 이해 커리큘럼
### — 자작 서보모터 실습을 통한 다이나믹셀/스마트 액추에이터 완전 이해 과정

---

## 1. 과정 개요

| 항목 | 내용 |
|---|---|
| **교육 목표** | 서보모터(모터+센서+제어루프) 구조를 직접 만들며 체득하고, <br> 이를 바탕으로 로보티즈 다이나믹셀, 로봇팔(OpenManipulator 등), <br>터틀봇 등 상용 스마트 액추에이터를 "원리를 아는 상태"로 활용할 수 있도록 함 |
| **교육 철학** | 블랙박스로 주어진 완제품을 사용법만 익히는 대신, <br>성능이 다소 부족한 자작 서보를 먼저 경험시켜 "왜 상용 제품이 이렇게 설계되었는가"를 <br>스스로 깨닫게 유도 |
| **대상** | 임베디드/로봇공학 기초를 마친 학생 또는 실무자 (아날로그/디지털 전자, C언어, 기초 제어이론 선수 필요) |
| **총 교육 시간(권장)** | 32~40시간 (4~5일 집중과정 또는 8주 주1회 과정) |
| **핵심 산출물** | 1) 자작 위치제어 서보 모듈, 2) 다이나믹셀 레지스터-자작 변수 매핑표, <br>3) (심화) UART 통신 프로토콜 기반 다중 서보 제어 시스템, 4) 최종 로봇팔/터틀봇 응용 실습 |

---

## 2. 커리큘럼 구조 (4단계)

```
1단계: 서보모터란 무엇인가 (최소 구성 체험)
        ↓
2단계: 다이나믹셀과 비교하며 이해 심화
        ↓
3단계: 통신 프로토콜 흉내내기 (심화, 선택)
        ↓
4단계: 실전 적용 — 로봇팔 / 터틀봇
```

---

## 3. 1단계: 서보모터란 무엇인가 — 최소 구성 체험

**교육 시간(권장)**: 8~10시간
**학습 목표**: 되먹임 제어(feedback control)의 원리를 몸으로 이해하고, "서보 = 모터 + 센서 + 제어루프"라는 3요소 구조를 체득한다.

### 3-1. 이론 강의 (2시간)
- 서보모터 vs 일반 DC모터의 차이
- 개루프(open-loop) 제어와 폐루프(closed-loop) 제어의 개념
- 피드백 센서의 역할 (포텐셔미터 원리: 각도 → 저항 → 전압)
- P(비례) 제어의 수학적 정의: `출력 = Kp × (목표각도 - 현재각도)`

### 3-2. 실습 준비물
- DC 기어드 모터 (또는 RC서보를 분해하여 내부 모터+기어박스만 재사용)
- 회전형 포텐셔미터 (모터 출력축과 기계적으로 연결)
- MCU (STM32 Nucleo 또는 Arduino) + 모터 드라이버(H-bridge, 예: TB6612FNG)
- 브레드보드, 전원, 오실로스코프(선택, 파형 관찰용)

### 3-3. 실습 단계

| 단계 | 실습 내용 | 산출물/확인사항 |
|---|---|---|
| 1 | 포텐셔미터 값을 ADC로 읽어 시리얼 모니터에 각도 출력 | 각도-전압 선형성 확인 |
| 2 | 목표각도(가변저항 또는 시리얼 입력)와 현재각도의 오차 계산 | 오차값 실시간 출력 |
| 3 | 오차에 비례한 PWM을 모터에 인가 (P제어 구현) | 모터가 목표각도로 움직이는지 확인 |
| 4 | Kp 값을 여러 단계로 변경하며 거동 관찰 | 오버슈트/진동/응답속도 트레이드오프 표로 정리 |
| 5 | (선택) I, D 항 추가하여 PID로 확장 | 정상상태 오차 개선, 오버슈트 감소 관찰 |

### 3-4. 핵심 깨달음 포인트 (교수자 강조사항)
- 포텐셔미터의 노이즈로 인해 목표값 근처에서 미세하게 떨리는 현상(dead-band 필요성) 체험
- Kp가 너무 크면 진동, 너무 작으면 느린 응답 → "튜닝"이라는 개념의 필요성 체감
- **의도적으로 완성도가 낮은 결과를 경험시킨다** (교육 설계상 핵심 원칙)

### 3-5. 평가/체크포인트
- [ ] 목표각도 입력 시 모터가 해당 각도로 수렴하는가
- [ ] Kp 변화에 따른 거동 차이를 본인 언어로 설명할 수 있는가
- [ ] "서보=모터+센서+제어루프" 구조도를 직접 그릴 수 있는가

## 4. 2단계: 다이나믹셀과 비교하며 이해 심화

**교육 시간(권장)**: 8~10시간
**학습 목표**: 자작 서보와 실제 다이나믹셀을 나란히 비교하며, 상용 제품의 설계 선택 하나하나가 어떤 문제를 해결하기 위한 것인지 이해한다.

### 4-1. 비교 실습 준비물
- 1단계에서 만든 자작 서보
- 다이나믹셀 X시리즈 실물 (예: XL330 또는 XM430) 1~2개
- U2D2 (또는 OpenCM485) + Dynamixel Wizard 2.0 소프트웨어

### 4-2. 비교 학습 매핑표

| 비교 항목 | 자작 서보 (1단계) | 다이나믹셀 | 왜 이렇게 설계했는가 |
|---|---|---|---|
| 위치센서 | 포텐셔미터 (아날로그) | 자기 엔코더 (AS5600급, 절대각도) | 마모 없음, 노이즈 적음, 절대위치 즉시 파악 |
| 제어루프 | 외부 MCU에서 소프트웨어 구현 | 내장 MCU에서 자체 실행 | 독립성, 실시간성, 버스 부하 감소 |
| 게인 설정 | 코드에 하드코딩 | 레지스터로 실시간 read/write (Position P/I/D Gain) | 부하 조건별 현장 튜닝 필요성 |
| 통신 | 없음 (개별 배선) | TTL 하프듀플렉스 데이지체인 (ID 기반) | 배선 단순화 + 다축 개별 제어 |
| 제어모드 | 위치제어만 | Position/Velocity/Current/Extended Position 등 다중모드 | 용도별(관절, 그리퍼, 바퀴 등) 최적화 |
| 보호기능 | 없음 | 과전류/과열/전압 이상 시 Shutdown | 하드웨어 보호, 안전성 |
| 상태 모니터링 | 없음 | 온도/전압/부하 실시간 레지스터 조회 | 진단, 예지보전 |

### 4-3. 실습 활동
1. Dynamixel Wizard로 실제 다이나믹셀의 레지스터 테이블(Control Table)을 열람
2. `Position P Gain`, `Position I Gain`, `Position D Gain` 항목을 찾아 1단계 자작 서보의 Kp/Ki/Kd와 1:1 매칭
3. Torque Enable, Return Delay Time, Temperature Limit 등 항목을 하나씩 살펴보며 "이게 왜 필요한가"를 조별 토의
4. 동일한 부하(추 매달기 등)를 자작 서보와 다이나믹셀에 각각 걸어 거동 비교 (자작 서보의 한계 체감)

### 4-4. 평가/체크포인트
- [ ] 다이나믹셀 Control Table의 주요 레지스터 5개 이상을 설명할 수 있는가
- [ ] 자작 서보의 한계점 3가지 이상을 다이나믹셀의 해결책과 짝지어 설명할 수 있는가

## 5. 3단계: 통신 프로토콜 흉내내기 (심화, 선택 과정)

**교육 시간(권장)**: 8~10시간
**학습 목표**: 다이나믹셀 방식의 ID 기반 데이지체인 통신을 직접 구현하여, 왜 이런 통신 구조가 필요한지 완전히 체감한다.

### 5-1. 실습 내용
1. 간단한 통신 프로토콜 설계
   - 패킷 구조 예: `[헤더][ID][명령어][데이터][체크섬]`
   - 명령어 종류: 위치설정(Write), 위치읽기(Read), Ping
2. UART 하프듀플렉스(1선 송수신) 구현 — 다이나믹셀과 동일한 방식 체험
3. 자작 서보 2~3대에 각각 ID 부여, 하나의 버스에 데이지체인 연결
4. 마스터(MCU 또는 PC)에서 ID를 지정하여 개별 모터에 위치 명령 전송
5. (선택) 여러 대를 동시에 움직이는 Sync Write 흉내내기

### 5-2. 핵심 깨달음 포인트
- 개별 배선이 아닌 버스 방식이 왜 배선/확장성 측면에서 유리한지
- ID 충돌, 통신 타이밍 문제 등을 직접 겪으며 프로토콜 설계의 어려움 체감
- 실제 Dynamixel Protocol 2.0의 패킷 구조와 본인이 만든 프로토콜을 비교

### 5-3. 평가/체크포인트
- [ ] ID 기반으로 여러 대의 자작 서보를 개별 제어할 수 있는가
- [ ] 본인이 설계한 프로토콜과 Dynamixel Protocol의 차이점을 설명할 수 있는가

---

## 6. 4단계: 실전 적용 — 로봇팔 / 터틀봇

**교육 시간(권장)**: 8~10시간
**학습 목표**: 1~3단계에서 쌓은 원리 이해를 바탕으로, 실제 다이나믹셀 기반 로봇 시스템을 "이해하며" 다루는 능력을 완성한다.

### 6-1. 실습 내용

| 실습 | 내용 |
|---|---|
| 로봇팔 조립/구동 | OpenManipulator 또는 유사 다이나믹셀 기반 로봇팔 조립, Position Control Mode로 관절 제어 |
| 제어모드 선택 실습 | 그리퍼는 Current-based Position Control, 관절은 Position Control 등 용도별 모드 선택 근거를 직접 판단·설명 |
| 터틀봇 구동계 분석 | 터틀봇3의 XM430 휠 모터가 Velocity Control Mode로 동작하는 이유 분석 |
| 트러블슈팅 실습 | 의도적으로 과부하/과열 상황을 만들어 Shutdown 동작 및 레지스터 상태 확인 |
| 종합 프로젝트 | 간단한 픽앤플레이스 또는 라인트레이싱 등 미니 프로젝트를 통해 배운 내용 통합 적용 |

### 6-2. 최종 평가
- 로봇팔/터틀봇의 제어모드 설정을 스스로 판단하고 그 근거를 설명하는 발표/시험
- 1단계 자작 서보 ~ 4단계 상용 로봇 적용까지의 학습 여정을 정리한 포트폴리오 제출

## 7. 전체 커리큘럼 요약표

| 단계 | 핵심 주제 | 시간 | 산출물 |
|---|---|---|---|
| 1단계 | 최소 구성 서보 (포텐셔미터+PID) | 8~10h | 위치제어 자작 서보 |
| 2단계 | 다이나믹셀 비교/레지스터 매핑 | 8~10h | 비교 매핑표, 한계 체감 리포트 |
| 3단계 (선택) | 통신 프로토콜 구현 | 8~10h | 다중 서보 데이지체인 제어 시스템 |
| 4단계 | 로봇팔/터틀봇 실전 적용 | 8~10h | 종합 프로젝트, 포트폴리오 |

**총 교육시간**: 24~30시간 (3단계 제외 시) / 32~40시간 (전 단계 포함 시)

## 8. 준비물 리스트 (전체 과정 기준)

- DC 기어드 모터 또는 분해용 RC서보
- 회전형 포텐셔미터
- STM32 Nucleo 보드 또는 Arduino (학생 수만큼)
- 모터 드라이버 IC (TB6612FNG 등)
- 다이나믹셀 X시리즈 (XL330/XM430 등) — 조당 1~2개
- U2D2 통신 인터페이스 + Dynamixel Wizard 2.0
- OpenManipulator 또는 유사 로봇팔 키트
- 터틀봇3 (또는 XM430 구동계 단품)
- 오실로스코프(선택), 브레드보드, 점퍼선, 전원공급장치

## 9. 교수자 유의사항

1. **1단계에서 절대로 완벽한 결과를 미리 보여주지 말 것** — 학생이 직접 한계를 겪어야 2단계 학습효과가 극대화됨
2. 2단계에서 다이나믹셀 레지스터를 하나씩 볼 때마다 "이게 왜 필요했을까?"를 먼저 학생에게 질문하고, 답을 유도한 뒤 설명하는 방식 권장
3. 3단계는 선택 과정이지만, 심화반/장기과정에서는 반드시 포함 권장 (통신 프로토콜 이해가 실무에서 가장 큰 차별점을 만듦)
4. 4단계 최종 평가는 단순 조작 숙련도가 아니라 "왜 이 설정을 선택했는가"에 대한 설명 능력을 중심으로 평가
